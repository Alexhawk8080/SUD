# Акт уничтожения гражданских дел

Программа автоматизирует подготовку **«Акта о выделении к уничтожению
документов (гражданские дела)»**: читает исходную таблицу дел, склоняет
ФИО, определяет сроки хранения по номенклатуре, формирует заголовки дел
и выгружает результат в Excel или Word.

Порт VBA-макроса Excel на Python с веб-интерфейсом.

## Возможности

- **Обработка дел** — загрузка Excel-таблицы, склонение ФИО
  (родительный / дательный падеж), определение сроков хранения,
  сквозная нумерация, выгрузка в Excel или Word по шаблону.
- **Проверка категорий** — поиск дел без типовой категории
  («о взыскании...», «О защите прав потребителей»), аналоги по истцу,
  словарь «истец → категория», автоисправление.
- **База данных** — организации (по иску / по заявлению), правила сроков
  хранения, судебные участки (9 реквизитов на участок), настройки.
  SQLite. Редактируется через веб-интерфейс. Импорт / экспорт в Excel.
- **Конвертация Excel ↔ Word** — в обе стороны. Из «Результата обработки»
  в Word-акт по шаблону и обратно. Невидимые метки в файлах, определение
  года из номеров дел, восстановление пропущенных номеров.
- **Внутренняя опись** — конвертация Word-описи в лист «Таблица» Excel.

## Быстрый старт

### Требования

- Python 3.10+ (проверено на 3.12)
- Windows / Linux / macOS

### Установка

    python setup_env.py

Создаёт `.venv` и устанавливает зависимости
(`flask`, `openpyxl`, `python-docx`, `pymorphy3`).
Учитывает корпоративный SSL-сертификат (`--trusted-host` для pip).

### Проверка

    .venv\Scripts\python.exe run_tests.py

Прогоняет все модули тестов. Ожидается: все OK.

### Запуск

    .venv\Scripts\python.exe court_case_app\app.py

Браузер откроется автоматически на http://127.0.0.1:5000.

При закрытии вкладки сервер останавливается сам (heartbeat + watchdog).

## Использование

Страницы приложения:

1. **Обработка** — загрузка исходной таблицы, параметры, формат
   результата.
2. **Проверка категорий** — поиск и исправление проблемных дел.
3. **База данных** — организации, правила сроков, судебные участки,
   настройки.
4. **Конвертация** — Excel ↔ Word.
5. **Внутренняя опись** — Word-опись в Excel.

### Типовой сценарий

1. Открыть страницу «Обработка».
2. Перетащить Excel-файл с делами.
3. Указать год, выбрать судебный участок (если заведён).
4. Выбрать формат: Excel или Word.
5. Нажать «Обработать» → предпросмотр → скачать.

    ├── app.py                # Flask-приложение, роуты

    │   ├── genitive.py       # родительный падеж (порт VBA)

    │   ├── word_writer.py    # Word по шаблону
    │   ├── category_check.py # проверка категорий
    │   ├── legacy_reader.py  # разбор старых результатов
    │   └── ...
    ├── database/             # SQLite (создаётся при запуске)

    ├── templates/            # HTML

## Тесты

Тесты покрывают все слои: склонение ФИО, сроки хранения, чтение / запись
Excel, генерацию Word, работу с БД, конвертацию, парсинг акта, UI.

    .venv\Scripts\python.exe run_tests.py

Единая точка прогона — `run_tests.py`: запускает каждый модуль
`tests/test_*.py` и собирает итог.
