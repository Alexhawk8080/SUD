# План разработки: Python-программа обработки гражданских дел

## О проекте

Перенос VBA-макроса Excel (обработка гражданских дел для акта уничтожения документов) на Python с веб-интерфейсом.

- **Исходники VBA:** `Module1.bas`, `родительный_падеж.bas`, `дательный_падеж.bas`
- **Word-шаблон:** `АКТ уничтожения гражданских дел.docx` (размечен плейсхолдерами `{{...}}`)
- **Технологии:** Flask + HTML/JS, SQLite, openpyxl, python-docx, PyInstaller
- **Язык интерфейса:** русский

## Принятые решения (зафиксированы с пользователем)

| Аспект | Решение |
|---|---|
| Интерфейс | Flask + HTML/JS, локальный сервер, автозапуск браузера |
| Запуск | Один `.exe` (PyInstaller), без установки Python |
| Исходные данные | Excel-файл; автоопределение столбцов + ручной маппинг при несовпадении |
| База данных | SQLite, встроенная, редактирование через интерфейс |
| Состав БД | Организации (название → тип подачи), слова-исключения, категории→сроки хранения |
| Склонение ФИО | Перенос VBA-логики 1:1 (результаты идентичны) |
| Сроки хранения | Формат как в VBA: «3 года Ст. 227» |
| Excel-результат | Новый `.xlsx`, настраиваемый набор столбцов |
| Word-результат | Гибрид: плейсхолдеры `{{...}}` + строка-образец таблицы |
| Нумерация | Сквозная по всему диапазону номеров (пустые строки для пропусков) |
| Предпросмотр | Таблица результата в браузере перед скачиванием |
| Документация | `Plan.md` — план и прогресс, `context.md` — контекст беседы (обновлять после каждого этапа) |
| Тестирование | Всестороннее на каждом этапе (чек-листы ниже) |

## Плейсхолдеры Word-шаблона

| Плейсхолдер | Значение |
|---|---|
| `{{судебный_участок}}` | Номер судебного участка (5 мест) |
| `{{судья}}` | ФИО мирового судьи |
| `{{дата_утверждения}}` | Дата утверждения акта |
| `{{дата_акта}}`, `{{номер_акта}}` | Дата и номер акта |
| `{{номер}} {{заголовок}} {{даты}} {{номер_описи}} {{номер_ед_хр}} {{количество}} {{срок}} {{примечание}}` | Строка-образец таблицы |
| `{{итого}}`, `{{год_дел}}` | Итоговая строка «Итого N (прописью) гражданских дел за YYYY год» |
| `{{секретарь}}`, `{{дата_подписи}}` | Подпись секретаря |
| `{{протокол_эк_дата}}`, `{{протокол_эк_номер}}` | Блок СОГЛАСОВАНО |

### Доработка 6. Проверка и исправление категорий дел — [x] ВЫПОЛНЕНА (2026-09-18)

Запрошена пользователем: выявлять дела без типовой категории («о взыскании...», «О защите прав потребителей» и т.п.), искать аналоги по истцу, предлагать исправления, группировать оставшиеся для ручного заполнения.

**Решения (согласованы с пользователем в обсуждении):**
- Проблемное дело — категория пустая ИЛИ в ней нет «о/об» (вариант В).
- Истец сопоставляется комбинированно: организации — по первому слову (справочник БД + аббревиатуры ООО/АО/ПАО/ЗАО/ИП/МУП/ГУП/НАО/ОАО...), физлица — по нормализованному полному тексту.
- Предложение категории: мода среди аналогов текущего файла + список всех вариантов; аналоги файла приоритетнее словаря БД.
- Словарь БД `case_categories`: «истец → несколько категорий»; пополняется кнопкой «Сохранить в БД»; автоисправление берёт самую частую категорию; при ручном исправлении — выбор из списка.
- Автоисправление: подстановка из словаря в обработку + контрольная таблица; чекбокс на странице проверки + глобальная настройка `auto_fix_categories` в БД.
- Отдельная страница «Проверка категорий» со своей загрузкой файла; поддержка исходных таблиц и готовых результатов (.xlsx/.docx с разбором заголовков).
- Таблица проблемных дел: № дела, истец, текущая категория, редактируемая предложенная, раскрытие аналогов.
- Секция «Без аналогов»: группы истцов, поле категории + «Применить ко всем», скачивание .xlsx только этой секции.
- Обработка с неисправленными делами разрешена (предупреждение со счётчиком); валидация «о/об» — предупреждение без блокировки.
- Кнопка «Обработать» — для всех типов файлов; из старых результатов акт строится с предупреждением о неполноте данных.
- Охват проверки — только дела, попадающие в результат (год + галочка алиментов).
