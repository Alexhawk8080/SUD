Импорт / экспорт базы данных

Экспортировать базу в Excel

Импорт читает лист «База данных»: колонка A — первое слово организации, колонка B — тип подачи (как в файле «АКТ уничтожения гражданских дел N.xlsm»). Существующие записи не перезаписываются.

Правила сроков хранения (корень слова → тип)

Порядок важен: первое совпадение корня в слове категории определяет срок. Дефолт для прочего — «3 года Ст. 227».
