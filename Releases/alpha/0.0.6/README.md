# Акт уничтожения гражданских дел — релиз 0.0.6-alpha

**Дата сборки:** 2026-09-27
**Канал:** alpha
**Версия:** 0.0.6

## О релизе

Новая база дел с иерархией **«судебный участок → год → файл → дела →
результат»**. Обработка и конвертация теперь работают через БД, а не
на разовых файлах.

## Возможности

- **База дел** — постоянный сайдбар с деревом «участок → год» на всех
  страницах.
- **Страница года** — 5 табов: Реквизиты / Файлы / Дела / Обработка /
  Результат.
- **Загрузка файла в БД** — версии сохраняются; можно переключать
  актуальную, скачивать, удалять. Разобранные дела — в БД.
- **Обработка из БД** — по актуальной версии источника; результат
  сохраняется в БД (перезаписывается при повторе).
- **Экспорт** — Word (.docx) по шаблону, Excel (.xlsx) — из сохранённого
  результата.
- **Реквизиты по годам** — 9 полей на «участок + год»; копирование
  реквизитов между годами; флаги is_closed / is_incomplete.
- **Проверка категорий** — снимки хранятся (N последних на файл).
- **Описи** — место в БД зарезервировано (модуль в следующих версиях).
- **Конвертация Excel ↔ Word** — отдельная страница для разовых операций.
- **Внутренняя опись** — отдельная страница.

    .venv\Scripts\python.exe court_case_app\app.py

## Миграция со старой версии

Если у вас БД от версии 0.0.5 или раньше:

    .venv\Scripts\python.exe migrate_db_v2.py

Скрипт сделает бэкап `app.db.bak-<дата>`, перенесёт участок и реквизиты
в новую схему, удалит legacy-ключи из `settings`.

## Что НЕ включено

- `.venv/`, `app.db`, `uploads/`, `output/` — создаются автоматически
- Личные файлы (исходные `.xlsx`, логи)
