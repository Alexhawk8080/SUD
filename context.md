## Суть задачи

Перенести на Python VBA-макрос Excel, который автоматизирует подготовку «Акта о выделении к уничтожению документов (гражданские дела)»: читает исходную таблицу дел, склоняет ФИО, определяет сроки хранения по номенклатуре, формирует заголовки дел и выгружает результат в Excel или Word.

**Требование пользователя:** программа должна выполнять «то же самое», что и VBA-макрос, с пользовательским интерфейсом, на одном компьютере, запуск по двойному клику, без установки Python.

## Принятые решения (по вопросам пользователя)

1. **Интерфейс:** Flask + HTML/JS (выбран из-за полного контроля над видом; Streamlit отклонён).
2. **Входные данные:** исходная таблица — Excel-файл, загружается через интерфейс.
3. **База данных:** встроена в программу, редактируется через интерфейс.
4. **Состав БД:** организации (название → «по иску»/«по заявлению»), слова-исключения (не склоняются), словарь «категория дела → срок хранения и статья» (перенос `GetRetentionInfo`).
5. **Результат:** на выбор пользователя — Excel-файл или Word-документ по шаблону.
6. **Структура исходной таблицы:** как в VBA (те же столбцы, заголовки в первой строке), при несовпадении — ручной маппинг столбцов через интерфейс.
7. **Склонение ФИО:** перенос VBA-логики 1:1 (pymorphy2 отклонён — результаты отличались бы, проверенная логика надёжнее).
8. **Запуск:** один компьютер, двойной клик, сборка в .exe (PyInstaller), без установки Python.
9. **Excel-результат:** новый .xlsx, настраиваемый набор столбцов.
10. **Word-результат:** гибрид — заполнение плейсхолдеров + вставка таблицы дел (строка-образец дублируется под каждое дело).
11. **Нумерация:** сквозная по всему диапазону номеров (min–max), пустые строки для пропущенных дел, как в VBA.
12. **Предпросмотр:** таблица результата в браузере перед скачиванием.
13. **Сроки хранения:** формат как в VBA «3 года Ст. 227» (без скобок и слова «Перечня»).
14. **Хранилище:** SQLite (отклонён JSON — надёжность при редактировании через интерфейс).
15. **Документация:** `Plan.md` (план + прогресс) и `context.md` (контекст, обновляется после каждого этапа).
16. **Тестирование:** всестороннее на каждом этапе (чек-листы в `Plan.md`).

## Технические детали из VBA-кода (важно для порта)

### Формат номера дела
`ПРЕФИКС-NNN/ГГГГ` (например, `2-123/2023`). Проверка: `IsValidCaseNumber` — наличие «-» и «/», год в конце совпадает с целевым.

### Роли столбцов исходной таблицы (индексы 1-based)
| Колонка | Роль |
|---|---|
| B (2) | Дата начала |
| C (3) | № дела |
| D (4) | Заявители |
| E (5) | Ответчики |
| F (6) | Категория дела |
| G (7) | № описи |
| H (8) | № ед.хр. |
| J (10) | Примечание |
| N (13, B+11) | Дата окончания (при ошибке — дата начала) |

### Заголовок дела
`Гражданское дело №{номер} {по иску|по заявлению} {заявители (род. падеж)} к {ответчики (дат. падеж)} {категория в нижнем регистре}`

### Определение «по иску/по заявлению»
По списку организаций: если заявитель — организация из справочника, у которой тип «по иску» → «по иску», иначе «по заявлению». Организации определяются по первому слову ФИО/названия (слова-исключения).

### Категория дела
Извлекается как текст после « О » или « Об » в категории (например, «о расторжении брака»).

### Сроки хранения (GetRetentionInfo) — соответствие корней
| Корень | Тип | Результат |
|---|---|---|
| алимент* | aliens | «1 год ЭК Ст. 139» (или 140 при «друг»; «изменен»/«размер» тоже 139) |
| расторжен*, брак | divorce | «3 года ЭК Ст. 137» |
| жилищн*, коммунальн*, платеж* | housing | «3 года Ст. 179» |
| страхов*, взнос* | insurance | «3 года Ст. 201» |
| пенсион*, пенси*, выплат* | pension | «5 лет ЭПК Ст. 203» (перерасчет → 202, нарушен → 203) |
| перерасчет* | pension_recalc | «5 лет ЭПК Ст. 202» |
| потребител* | consumer | «3 года ЭПК Ст. 208» |
| налог* | tax | «3 года Ст. 221» |
| займ*, долг* | loan_debt | «3 года Ст. 222» |
| кредит* | credit_loan | «3 года Ст. 223» |
| взыскани* | collection | (в Select Case отсутствует → дефолт) |
| прочее/не найдено | — | «3 года Ст. 227» |

**Важно:** порядок ключей критичен — «пенси» перекрывает более длинные корни; в Python реализовано списком кортежей.
**Особенность VBA (сохранена 1:1):** слово «взыскании» в начале категории → корень «взыскани» → collection → нет ветки в Select Case → всегда «3 года Ст. 227», даже если далее есть «алименты»/«налог». Зафиксировано тестами; пользователь может изменить правила через БД (этап 8).

### Склонение (ключевые правила)
- Пол определяется по отчеству: окончание «-на» или «-кызы» → женский.
- Женская фамилия у мужчины → маскулинизация (ова/ева/ёва/ина/ая/яя/ская/цкая).
- Старая фамилия в скобках склоняется обеими формами.
- «оглы/кызы» не склоняются.
- Исключения имён: Павел/Лев/Пётр/Любовь/Али/Бали (обе функции).
- Имена на «-ия» в дательном: Мария → Марии (проверка предпоследней буквы).

Результат в реальной работе: сервер работал непрерывно ~1 час (лог 15:59-16:59, heartbeat каждые 4 с, переходы между страницами, свёрнутое окно), остановился сам через ~20 с после закрытия вкладки; ошибок в логе нет.
